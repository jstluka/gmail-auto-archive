# gmail-auto-archive
Auto-archive messages after a given length of time in inbox.

I created the scripts here in conjunction with some Gmail filters to declutter a shared work email inbox.

Various notifications that are only relevant for a few hours can be auto-archived after six hours (i.e., "... has joined your Zoom room", "... has declined an invite", etc.), while emails pertaining to taxes should not be archived until later in the month.

The unstarOldEmails script allows one to star emails that should be brought to the attention of other team members, and automatically removes the star at a time when this email is almost certainly no longer relevant.
